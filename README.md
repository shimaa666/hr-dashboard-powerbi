# 👩‍💼 HR Dashboard – Power BI

## 📊 Overview
This project presents an interactive HR dashboard built using Power BI to analyze workforce performance, employee turnover, and recruitment sources.

## 🎯 Objectives
- Monitor employee performance and workforce distribution
- Analyze turnover trends and identify key reasons
- Evaluate recruitment channels effectiveness
- Support HR decision-making

## 📈 Key Features
- KPI Cards: Total Employees, Active Employees, Turnover Rate, Avg Salary, Avg Tenure
- Turnover analysis across departments
- Recruitment source analysis (LinkedIn, Indeed, etc.)
- Manager impact on employee satisfaction
- Decomposition Tree for root cause analysis

## 🛠 Tools & Technologies
- Power BI
- DAX
- Data Visualization
- Data Analysis
